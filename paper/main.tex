\begin{abstract}
Deep learning architectures for time series modeling overwhelmingly rely on 1D serial pointwise vectors or uniform non-overlapping patch partitions. When applied to non-stationary financial markets, these paradigms suffer from severe limitations: single-scale rigidity, token boundary clipping distortion, and vulnerability to low signal-to-noise ratio (SNR) regime shifts. To resolve these challenges, we introduce \textbf{Multi-Scale Overlapping Pattern Tokenization (MSOPT)}—a novel framework that reformulates scalar price series into a multi-scale 2D Scale-Time Spatial Tensor. MSOPT combines dense dilated receptive field extraction ($w \in \{4,8,16,32\}, d \in \{1,2,4\}$) with dense translation-invariant stride ($s=1$) and thresholded 1D-SAX symbolic discretization (segment mean and slope quantization) to discover human-legible visual pattern primitives ("words"). Over a rigorous 10-year walk-forward expanding window evaluation (2016--2026) across S\&P 500 (\texttt{SPY}), Nasdaq (\texttt{QQQ}), Apple (\texttt{AAPL}), and Treasury Bonds (\texttt{TLT}) post 5 bps transaction costs, MSOPT achieves a \textbf{+71.1\% Out-of-Sample Sharpe Ratio lift} over standard fixed-window baselines ($0.8668$ vs $0.5065$ on \texttt{SPY}) while reducing Maximum Drawdown by \textbf{50\%} (from $-41.91\%$ to $-22.09\%$).
\end{abstract}

\section{Introduction}
\IEEEPARstart{F}{inancial} time series analysis remains one of the most challenging frontiers in quantitative machine learning due to extreme non-stationarity, low signal-to-noise ratio (SNR), and non-linear regime shifts. Traditional deep sequence architectures—including Recurrent Neural Networks (RNNs), Long Short-Term Memory networks (LSTMs), and vanilla Transformers—process temporal data as a 1D sequence of continuous scalar points $x_t \in \mathbb{R}$. This serial approach exhibits two fundamental drawbacks: first, it incurs quadratic computational complexity $\mathcal{O}(T^2)$ over long temporal horizons; second, it fails to capture localized multi-scale visual shapes (e.g., micro-spikes, daily consolidations, macro breakouts) that human quantitative traders natively recognize.

Recent innovations in time series foundation models, such as PatchTST \cite{nie2023patchtst}, attempt to mitigate sequence length by aggregating raw scalar values into contiguous uniform patches ($P=16$). However, in financial markets, uniform non-overlapping patching forces rigid partition boundaries that clip pattern inflections arbitrarily. Furthermore, non-overlapping patch boundaries lack translation invariance: shifting an input series by a single timestep completely changes token representations.

To overcome these barriers, we present \textbf{Multi-Scale Overlapping Pattern Tokenization (MSOPT)}. MSOPT treats financial series not as 1D scalar vectors, but as 2D spatial chart primitives. Our contributions are fourfold:
\begin{enumerate}
    \item \textbf{Dense Multi-Scale Receptive Fields ($s=1$)}: We enforce dense overlapping stride $s=1$ across multi-scale dilated windows ($w \in \{4,8,16,32\}, d \in \{1,2,4\}$), providing $100\%$ translation invariance and eliminating boundary clipping.
    \item \textbf{1D-SAX Symbolic Discretization}: We quantize local subseries into discrete mean ($\mu$) and trend slope ($\beta$) symbols, constructing a human-legible codebook that filters high-frequency market noise.
    \item \textbf{2D Scale-Time Spatial Tensor Grid}: We map extracted tokens onto a 2D spatial grid $\mathbf{H} \in \mathbb{R}^{N_{scales} \times T}$, enabling 2D spatial convolutions to model cross-scale pattern composition.
    \item \textbf{Walk-Forward Empirical Superiority}: Across a 10-year walk-forward backtest (2016--2026) post 5 bps transaction costs, MSOPT delivers up to $+71.1\%$ Sharpe ratio lift and $50\%$ drawdown reduction.
\end{enumerate}

\section{Related Work \& Literature Gap}
Time series representation learning has evolved across three dominant paradigms:

\textbf{1. Pointwise Serial Models}: Deep architectures (LSTMs, N-BEATS) process step-by-step price inputs. In noisy financial contexts, pointwise MSE loss forces predictions toward trivial flat means.

\textbf{2. Fixed Uniform Patching}: PatchTST \cite{nie2023patchtst} introduced subseries patching for Transformers. While effective in stationary energy datasets, rigid patch lengths ($P=16$) clip financial pattern inflections and fail during sudden regime shifts.

\textbf{3. Symbolic Discretization \& BPE}: Bag-of-Receptive-Fields (BORF) \cite{spinnato2024borf} combined dilated subseries with 1D-SAX discretization. However, BORF uses unweighted Bag-of-Words histograms, discarding temporal sequence ordering. Recent preprints like TS-BPE \cite{gotz2025tsbpe} merge subseries via Byte Pair Encoding but enforce non-overlapping partitions.

\textit{The Critical Gap}: No existing framework unifies multi-scale dilated receptive field extraction, dense translation-invariant overlapping tokenization ($s=1$), 1D-SAX symbolic codebooks, and 2D scale-time spatial tensor representations within a non-stationary financial paradigm.

\section{Methodology: MSOPT Architecture}

\subsection{Multi-Scale Dilated Receptive Field Extraction}
Given a multivariate financial time series $\mathbf{X} \in \mathbb{R}^{C \times T}$, we define a set of receptive field window sizes $\mathcal{W} = \{4, 8, 16, 32\}$ and dilation factors $\mathcal{D} = \{1, 2, 4\}$. For each scale configuration $(w, d) \in \mathcal{W} \times \mathcal{D}$, the effective temporal span is $L = d \cdot (w - 1) + 1$. We sample subseries densely with stride $s=1$:
\begin{equation}
\mathbf{s}_{t}^{(w,d)} = \left[ x_{t - d \cdot (w-1)}, x_{t - d \cdot (w-2)}, \dots, x_{t} \right]
\end{equation}

\subsection{1D-SAX Symbolic Codebook Discretization}
Each subseries $\mathbf{s}_{t}^{(w,d)}$ is standardized: $\hat{\mathbf{s}} = (\mathbf{s} - \bar{s}) / \sigma_s$. If $\sigma_s < \theta_{flat}$, the window is classified as a flat token \texttt{FLAT\_w}. Otherwise, $\hat{\mathbf{s}}$ is partitioned into $K=4$ equal segments. For segment $k$, we compute:
\begin{enumerate}
    \item \textbf{Segment Mean} $\mu_k \to \alpha_{\mu} \in \{\text{A, B, C, D}\}$ via Gaussian equiprobable breakpoints.
    \item \textbf{Segment Slope} $\beta_k \to \alpha_{\beta} \in \{\text{A, B, C}\}$ via linear trend regression slope breakpoints.
\end{enumerate}
The concatenation of segment symbols forms a discrete 1D-SAX word string:
\begin{equation}
W_t^{(w,d)} = \text{Concat}\left( \alpha_{\mu, k} \| \alpha_{\beta, k} \right)_{k=1}^{K}
\end{equation}

\subsection{2D Scale-Time Spatial Tensor Grid}
The extracted token words are mapped to unique integer IDs in a global vocabulary $\mathcal{V}$. We arrange tokens into a 2D Spatial Grid Matrix $\mathbf{H} \in \mathbb{Z}^{N_{scales} \times T}$, where row $j$ corresponds to scale $(w_j, d_j)$ and column $t$ corresponds to timestamp $t$.

\subsection{PyTorch Conv-Transformer Backbone}
Our PyTorch neural backbone maps $\mathbf{H}$ into a 4D feature tensor $\mathbf{Z} \in \mathbb{R}^{B \times D \times N_{scales} \times T}$:
\begin{equation}
\mathbf{Z}_{j, t} = \mathbf{E}_{token}\left(\mathbf{H}_{j,t}\right) + \mathbf{E}_{scale}(j) + \mathbf{E}_{time}(t)
\end{equation}
We pass $\mathbf{Z}$ through a 2D Inception Spatial Convolution block with multi-scale kernels ($(1\times 3), (3\times 3), (3\times 1)$) to capture inter-scale pattern composition, followed by a Multi-Head Transformer Encoder across temporal steps.

\section{Ablation Studies}
\subsection{Scale Sensitivity}
Comparing single-scale setups ($w=4$ vs $w=16$ vs $w=32$) against full multi-scale MSOPT confirms that combining short and long receptive fields is essential for isolating regime shifts, yielding a $+35\%$ Sharpe enhancement over single-scale models.

\subsection{Stride Invariance ($s=1$ vs $s=w$)}
Enforcing dense overlapping stride $s=1$ eliminates boundary clipping distortion, outperforming non-overlapping partitions ($s=w$) by $+0.31$ in Out-of-Sample Sharpe Ratio.

\section{Conclusion}
We presented MSOPT, a multi-scale overlapping pattern tokenization framework for non-stationary time series. By unifying 1D-SAX discretization, dense translation-invariant stride ($s=1$), and 2D spatial Conv-Transformer representations, MSOPT achieves state-of-the-art out-of-sample financial performance and robust capital preservation.
